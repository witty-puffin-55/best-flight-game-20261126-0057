Ridgeline Run is a bush-plane courier game: fly a mountain valley in chase view, thread glowing rings, drop parcels on high pads, and land on the strip with fuel to spare — three sorties with different goals, a live flight model with stalls and crosswind, and a lit instrument panel.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Fly with arrows or WASD, Shift/Ctrl for throttle, mouse to steer, B to drop a parcel, P to pause, R to restart.
